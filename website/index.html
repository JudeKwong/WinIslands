功能特性

一枚悬浮胶囊，覆盖日常使用全部场景。

媒体播放控制

兼容网易云、QQ 音乐、Spotify、Apple Music 等主流播放器，支持封面、进度拖拽、切歌与多播放器切换。

卡拉OK逐字歌词

逐字高亮跟随播放进度，支持本地 .lrc、AMLL TTML 与在线歌词，字号颜色均可自定义。

可定制组件系统

内置 30 余种组件（时间、天气、CPU、电量等），可独立开关、拖拽排序，支持单行紧凑布局与触摸手势。

上岛 API

内置本地 HTTP / WebSocket 服务，第三方软件可将文字、图片、进度推送至灵动岛，不影响既有组件。

文件中转站

拖文件至灵动岛即可临时挂载，二次拖拽至其他窗口即可传送，不复制文件实体。

系统事件提醒

蓝牙连接、充电、低电量等事件以动画横幅弹出，支持历史记录与白名单静音。

外观与动效

18 套主题、自定义强调色与毛玻璃效果，120fps 弹簧物理动画，完整适配高 DPI 与多显示器。

通知中心

汇总所有应用的 Toast 通知，可按应用名称或 AppUserModelId 允许或屏蔽，过期通知自动清理。

崩溃自动恢复

异常退出后自动重启并恢复状态，30 秒周期保存，配合托盘常驻与单实例机制，适合长期后台运行。

隐私安全

默认完全离线运行，无遥测、无广告、不收集数据，配置存放于本机可随时删除。

一眼看懂

紧凑、展开两种形态，支持单行模式与自动尺寸调节。

3.1.8 更新亮点

插件安全体系、可访问性与更新校验全面加固，构建与发布流程同步升级。

插件安全体系

插件入口文件必须通过 SHA-256 校验后才会运行，新增「校验并信任」、权限白名单与目录逃逸防护；插件进程纳入系统作业对象，未声明权限时禁止派生子进程。

可访问性与高对比度

按钮、输入框与滑块自动获得屏幕阅读器名称，通知支持语音播报；高对比度模式下自动切换系统颜色并关闭半透明光学层。

更新流程加固

下载完成后再次校验 SHA-256 与文件大小，校验失败立即清理临时文件；设置页实时显示下载进度，并支持一键重启完成安装。

更稳的构建与发布

升级 .NET 10，新增 Windows 与 macOS 双平台自动化构建流水线、安装包与签名脚本，并为每个发布资产生成 SHA256 校验清单。

给开发者

把你的软件送上灵动岛

WinIslands 内置本地 HTTP / WebSocket 服务（默认端口 9840），第三方程序可通过 REST 与 WebSocket 接口将文字、图片、进度与按钮推送至灵动岛。脚本、网页与原生应用均可接入，无需额外依赖。

  • POST /v1/island/push — 推送一张灵动岛卡片
  • PATCH /v3/island/push/{id} — 部分更新
  • GET /v3/ws — WebSocket 双向通道
  • 图片 · 动态进度 · 心跳续期 · 点击动作 · 自定义显示时长
