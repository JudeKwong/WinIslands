# WinIslands 常见问题（FAQ）

## 运行环境

**需要安装 .NET 运行时吗？**
不需要。发布的 Windows 版本是自包含单文件程序，.NET 运行时已打包在 exe 内部。

**支持哪些 Windows 版本？**
Windows 10 2004（19041）及以上、Windows 11，x64 与 ARM64 都有对应版本。系统需要开启「透明效果」与「桌面窗口管理器」合成（默认开启）。

**要安装还是直接用？**
两种都可以：
- **便携版**（`WinIslands-<版本>-win-x64.exe` / `win-arm64.exe`）：双击即用，不写注册表；删除文件即卸载。
- **安装包**（`WinIslands-Setup-<版本>.exe`）：写入开始菜单、可选开机启动，升级时自动替换旧版本。

## 功能

**支持哪些播放器？**
所有向 Windows 媒体会话（SMTC）上报状态的播放器都能识别，例如 Spotify、Windows 媒体播放器、新版网易云音乐 / QQ 音乐、浏览器里的网页播放器。Cider 有独立适配，可获得更完整的专辑信息。若播放器没有上报媒体会话，会自动回退到窗口标题识别。

**歌词从哪里来？**
优先级：播放器内嵌歌词（如 Cider）→ 本地歌词文件（`%APPDATA%\WinIslands\Lyrics`）→ 在线歌词。在线歌词只发送歌曲名、歌手、时长用于匹配，不上传任何账号信息。

**通知是怎么来的？**
通过 Windows 通知中心接口读取系统 Toast 通知，只在本机解析。首次启动会建立基线，不会把历史通知当成新消息。可以在「通知」页按应用开启或关闭。

**通知会保存历史吗？**
不会。通知以卡片形式在灵动岛上短暂显示，过期后自动消失，展开模式下不再保留历史列表。

**支持多显示器吗？**
支持。可以把岛拖到任意屏幕，位置与缩放按显示器分别记忆；切换 DPI 时会自动按新缩放重建尺寸。

**全屏时会不会挡游戏？**
默认在全屏应用、锁屏、省电模式下自动隐藏或降低刷新频率，可在设置里调整。

**可以在 macOS 上用吗？**
有独立的 macOS 版本（Intel / Apple Silicon），界面与交互按 macOS 习惯单独实现，不是简单移植。

## 数据与隐私

**会上传我的数据吗？**
不会。媒体信息、通知内容、插件输出全部在本机处理。只有在「检查更新」和「在线歌词匹配」时会发起网络请求，且不包含个人标识。崩溃日志与转储保存在本地 `%APPDATA%\WinIslands\logs`、`crashdumps`，不会自动上传。

**用户数据存在哪里？**
`%APPDATA%\WinIslands`：`settings.json`（设置）、`logs`（日志）、`Lyrics`（歌词缓存）、`plugins`（插件）、`crashdumps`（崩溃转储）。

**怎么彻底卸载？**
退出程序，删除 exe（或从「应用和功能」卸载安装版），再删除 `%APPDATA%\WinIslands` 即可。若设置了开机启动，卸载程序会自动移除对应启动项。

## 更新

**怎么更新？**
设置 → 关于 → 检查更新。新版本会先下载并校验 SHA-256 与文件大小，校验失败不会替换当前版本；替换过程由独立进程完成，失败时自动回滚到旧版本。

**更新会不会丢设置？**
不会。设置保存在 `%APPDATA%\WinIslands`，与程序文件分离。

## 其他

**和 macOS 灵动岛是同一套代码吗？**
不是。WinIslands 是独立的开源实现，按 Windows 的合成、媒体会话与通知模型重新设计，交互参考了灵动岛这一形态。

**可以自己写插件吗？**
可以，见 [插件开发指南](PLUGIN_DEVELOPMENT.md)。插件以独立子进程运行，崩溃或超时不会影响主程序。
