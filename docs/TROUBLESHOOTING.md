# 故障排查

先看「日志与信息收集」一节，多数问题能在日志里直接看到原因。

## 岛不出现 / 点了没反应

1. 确认托盘图标存在：图标在 = 进程存活；不在则程序已退出。
2. 检查设置 → 外观 → 显示位置，是否被拖到了已断开的显示器（可点「恢复默认位置」）。
3. 检查是否开启了「全屏时隐藏」，当前前台程序是否被判定为全屏。
4. 确认没有其他实例占用：WinIslands 是单实例程序，第二次启动会把已运行实例唤出。

## 展开后显示不全 / 收起后变直角

3.1.8 已重写展开/收起动画状态机，正常情况下不会再出现。若仍复现：

1. 记录复现步骤（连续展开收起几次、当时是否在播放音乐 / 有无通知）。
2. 检查显示缩放是否在切换过程中变化（例如把窗口拖到不同 DPI 的屏幕）。
3. 提供日志与截图反馈，日志中会记录 `expand/collapse` 状态机的最终尺寸与圆角校正结果。

## 歌词不显示

1. 先在媒体页确认能识别到播放器和曲目。识别不到时歌词不会加载。
2. 检查设置 → 歌词 → 在线歌词是否开启；关闭后只会使用本地与内嵌歌词。
3. 若歌曲是纯音乐或没有匹配歌词，会显示「暂无歌词」，属正常情况。
4. 本地歌词放在 `%APPDATA%\WinIslands\Lyrics`，文件名建议为 `歌手 - 歌名.lrc`。

## 收不到通知

1. Windows 设置 → 隐私和安全性 → 通知：确认允许应用访问通知，并已开启「允许应用访问你的通知」。
2. WinIslands 设置 → 通知：确认目标应用没有被关闭，且没有开启免打扰。
3. 通知中心已被清空或系统刚重启时，第一次轮询只建立基线，之后的新通知才会展示。
4. 部分应用（如以管理员权限运行的商店应用）不向普通权限进程暴露通知，需以相同或更高权限运行。

## 插件不加载

1. 插件目录：`%APPDATA%\WinIslands\plugins\<插件 id>\plugin.json`，或 exe 同级 `plugins` 目录。
2. 在设置 → 插件里点「重新扫描」，查看该插件的状态与最近错误输出。
3. 3.1.8 起插件需要确认权限并信任（首次运行会提示）；入口文件哈希变化会要求重新确认。
4. 检查 `plugin.json` 的 `command` / `timeout_seconds` / `permissions` 是否正确，详见 [插件开发指南](PLUGIN_DEVELOPMENT.md) 与 [插件安全说明](PLUGIN_SECURITY.md)。

## 自动更新失败

1. 设置 → 关于 → 检查更新，查看具体阶段：查询版本、下载、校验、替换。
2. 校验失败通常由网络中断或代理改写内容导致，重新下载即可。
3. 替换阶段失败：确认程序目录可写（便携版放在 `Program Files` 需要管理员权限）。
4. 若当前版本提示「已是最新」但仍想重装，可手动下载发布页的对应架构文件覆盖。

## 占用偏高

1. 设置 → 关于 / 性能：确认「后台节流」开启（锁屏、全屏、省电时自动降频）。
2. 关闭不用的组件（频谱、粒子、壁纸取色）。
3. 插件是独立进程，可在插件页停用可疑插件后观察。
4. 若内存持续增长，请附上任务管理器截图与运行时长反馈。

## 程序无法启动

1. 查看 `%APPDATA%\WinIslands\logs` 最新日志文件末尾的异常。
2. 若上次异常退出，程序会提示「已恢复」并使用上一次可用配置启动。
3. 尝试重命名 `%APPDATA%\WinIslands\settings.json` 后启动，用于排除配置损坏。

## 日志与信息收集

反馈问题时请附上：

- 版本号（设置 → 关于）
- Windows 版本与系统架构（x64 / ARM64）
- 显示缩放比例、显示器数量
- 复现步骤与期望结果
- `%APPDATA%\WinIslands\logs` 中对应时间的日志
